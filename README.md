# LeadGen Base 2.5.7

Парсер Яндекс Карт, макеты сайтов, Telegram и AI-ассистент.
Для работы не нужны установленный Python, PostgreSQL или системный Chrome.
Chromium и необходимые библиотеки уже в архиве.
Обновления программы: https://t.me/yanv_tg

## Запуск

1. Распакуйте весь ZIP в отдельную папку на компьютере.
2. Откройте «LeadGen Base.exe». Python и команды в терминале не нужны.
3. Откройте раздел «Инструкция»: там есть поиск и описание всех функций.
4. В «Яндекс Картах» выберите город из подсказок или введите его вручную,
   укажите рубрику и нажмите «Начать сбор».

Для Windows 10/11, 64 бита. Нужен интернет для Яндекс Карт и внешних сервисов.
Папки _internal и browsers должны оставаться рядом с EXE. Запускать EXE прямо
из окна архива или переносить только один EXE нельзя. Права администратора
для обычного запуска не требуются.

Chromium уже включён. Если его файлов нет, при запуске сбора программа сама
загрузит нужную версию. В «Яндекс Картах» есть кнопки проверки и восстановления
браузера. Для восстановления нужен доступ к официальным серверам Playwright.
Если загрузка не проходит, заново распакуйте полный архив.

Если WebView2 недоступен, интерфейс откроется в отдельном окне встроенного
Chromium. Устанавливать другой браузер для этого не нужно.

Если Яндекс покажет капчу, пройдите её в окне браузера. Фоновый режим парсера
для этого должен быть выключен. Сбор зависит от доступных карточек и ответов
Яндекс Карт; лимит не гарантирует наличие такого количества организаций.

Возможности Pro: отдельный пункт меню, кнопка в шапке и блок на главном экране.

## Настройки и файлы

Ярлык с иконкой: «Настройки» → «Создать ярлык на рабочем столе».
Для Telegram в настройках есть ссылка и инструкция получения API ID / hash
на my.telegram.org/apps. Сохраните их, затем введите номер, код и при необходимости
пароль 2FA. Для парсера Telegram и AI не нужны.
Свою папку после подключения Telegram не передавайте: в ней появляются личные
настройки и файл сеанса. Для публикации используйте исходный готовый ZIP выпуска.
Базы находятся в databases, готовые макеты — в websites рядом с EXE.

Чтобы перенести прежние базы, сначала сделайте копию старой папки программы,
закройте обе версии и скопируйте нужные XLSX в новую папку databases.
Не заменяйте новой версией старую папку целиком без резервной копии.

В поставке нет аккаунтов, ключей и клиентских баз автора.
SHA256SUMS.txt содержит контрольные суммы файлов этой версии.
Справочник городов: hflabs/city, https://github.com/hflabs/city, CC BY-SA 4.0.
Названия и регионы нормализованы, для крупных городов использованы прежние
оценки проекта. Порядок ориентировочный; это не текущая статистика населения.
Копия данных и атрибуция включены в _internal/assets/cities.json
и cities-data-license.txt. Лицензия данных не распространяется на код программы.

## Проверка файла

EXE пока не подписан сертификатом издателя. Проверка Defender и предупреждение
SmartScreen о неизвестном издателе — разные проверки. Отсутствие обнаружений
в одной проверке не гарантирует тот же результат у всех антивирусов.
Если файл блокируется, сообщите в канал точное название обнаружения и версию.
